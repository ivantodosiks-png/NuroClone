# NuroClone

Браузерная игра для ПК о физической гимнастике. Первая сцена — перекладина, мягкий мат и свобода экспериментировать с инерцией. Интерфейс на русском языке.

## Запуск

Нужен Node.js **22.12+** (или 20.19+).

```sh
npm install
npm run dev
```

Откройте адрес из терминала, обычно **http://127.0.0.1:5173**. Нажмите PLAY. CONTROLS показывает управление, BACK возвращает в меню. В Windows при запрете запуска `npm.ps1` используйте `npm.cmd install` и `npm.cmd run dev`.

Шрифт включён в проект через npm. Во время игры сеть, аккаунты и внешние ресурсы не нужны.

## Управление

| Клавиша | Действие |
| --- | --- |
| A / D | Раскачиваться на перекладине; вращать тело в полёте |
| W | Поднять прямые ноги к перекладине; отпустить — плавно опустить |
| L | Группировка: колени к груди, уменьшение момента инерции |
| K | Twist — инерционный аналог продольного вращения в 2D |
| Space | Только отпустить все активные хваты |
| R | Мгновенно начать попытку заново |
| Esc | Пауза / продолжение |

Раскачивайтесь A/D и подъёмом ног W, отпустите перекладину на подъёме. Захват автоматический: рука должна пройти не дальше 25 пикселей от тёмной части перекладины со скоростью не выше 9 м/с. После отпускания действует cooldown 450 мс. Руки хватаются независимо; возможно удержание одной или двумя руками. После приземления нажмите R для следующей попытки.

Esc или потеря фокуса ставит игру на паузу. RESUME продолжает попытку, RESTART начинает заново.

## Физическая модель

- Phaser **3.90** и встроенная в него версия **Matter.js**. Отдельный экземпляр Matter не подключается.
- **11 rigid bodies**: голова, корпус, таз, по две части каждой руки и ноги. Кисти — конечные точки предплечий. **10 физических constraints** соединяют части тела.
- Суставные PD-моторы прикладывают равные противоположные моменты к связанным частям. W поднимает прямые ноги, L сгибает бёдра и колени. A/D плавно добавляют моменты; при хвате — касательную силу для раскачивания. Без ввода тело висит с опущенными ногами.
- Matter.js остаётся 2D. K управляет дополнительной инерционной осью twist: torque изменяет угловой импульс, скорость зависит от массы и позы, отпускание K сохраняет вращение. Небольшая пара противоположных моментов нагружает настоящие суставы корпуса/таза. Хват и пол тормозят twist. Это игровой аналог продольного вращения, без 3D-коллизий.
- Шаг физики **120 Гц**, аккумулятор времени, не более 50 мс симуляции за кадр. На очень медленном устройстве симуляция замедляется вместо нестабильных больших шагов.
- Хват — отдельный constraint между статической перекладиной и концом предплечья. Его длина равна расстоянию в момент захвата: положения и скорости не перезаписываются. Отпускание удаляет только constraint. Проверка скорости учитывает вращение предплечья.
- Столкновения с полом и матом; столкновения частей Nuro друг с другом отключены для устойчивой 2D-модели. Опоры перекладины — декорации, сама зона хвата — sensor.
- Основное движение не содержит кадровой анимации, телепортации или записи координат персонажа каждый кадр. Начальные углы задаются только при создании тела. Камера плавно следует за корпусом и немного отдаляется на скорости.
- Векторная сцена рисуется Phaser Canvas Renderer. HTML/CSS используются только для меню и HUD. Фон использует повторяемую текстуру вместо тысяч отдельных примитивов.

Это управляемая аркадная физическая модель, без симуляции мышц человека. На земле Nuro остаётся ragdoll: ходьба и автоматический подъём не входят в первую тренировку.

## Структура

```text
src/
  config/constants.ts         Палитра, параметры мира и физики
  levels/TrainingLevel.ts     Перекладина, мат, пол, фон, след движения
  physics/matter.ts           Типы и функции работы с Matter
  physics/JointMotor.ts       Моторы суставов на основе torque
  player/Gymnast.ts           Составное тело, позы, отрисовка
  player/PlayerController.ts  Клавиатура и буфер коротких нажатий
  player/GrabSystem.ts        Независимые физические хваты
  player/TrickTracker.ts      Полные обороты, трюки и очки
  scenes/GameScene.ts         Игровой цикл, камера, рестарт, пауза
  scenes/MenuScene.ts         Стартовое меню
  ui/HUD.ts                  Score, Flips, Twists, Last Trick, Best Score
  ui/styles.css              Интерфейс
  main.ts                    Запуск Phaser
tests/game.spec.ts           Интеграционные проверки в браузере
```

В `src/config/constants.ts` настраиваются gravity, swingForce, rotationTorque, legRaiseStrength, legRaiseTargetAngle, tuckStrength, twistTorque, poseTransitionSpeed, autoGrabDistance, autoGrabMaxVelocity, autoGrabCooldown и пороги landing. Масштаб: 95 пикселей на метр.

Трюки считаются только после release, начиная с полных оборотов: Front/Back Flip, Double/Triple Flip, Twist, Double Twist, Flip + Twist и Regrab. Мелкие колебания не суммируются в оборот. Очки начисляются при успешном приземлении или повторном хвате; crash отменяет очки текущего полёта. Best Score сохраняется локально в браузере. Приземление проверяет реальные контакты стоп, положение корпуса и скорость до столкновения. Касание головой/спиной или превышение порогов — crash.

## Проверки и сборка

```sh
npm run typecheck
npm run build
npm run preview
```

`typecheck` проверяет исходники, тесты и конфигурации. Готовая статическая игра находится в `dist/`.

Браузерные тесты:

```sh
npx playwright install chromium
npm test
```

Для уже установленного Chrome можно не скачивать Chromium. В PowerShell:

```powershell
$env:PLAYWRIGHT_CHANNEL = 'chrome'
npm.cmd test
```

Тесты покрывают 18 пунктов этапа: простое меню, PLAY/CONTROLS/BACK, свободный вис, W и отпускание W, раскачивание, L, K, A/D, release, auto grab, flips/twists, regrab, landing/crash и R. Для точных проверок полёта тестовые fixtures задают начальные положения/скорости настоящих Matter-тел; в игровом управлении этого нет. Только в dev-сборке доступен read-only снимок физики `window.__NURO__.snapshot()`.
