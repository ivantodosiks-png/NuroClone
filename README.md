# NuroClone

Физическая sandbox-игра: раскачаться, отпуститься, вращаться и автоматически поймать перекладину обеими руками.

## Запуск

Node.js 22.12+ (или 20.19+).

```sh
npm install
npm run dev
```

Откройте адрес из терминала и нажмите PLAY. CONTROLS показывает управление, BACK возвращает в меню. В PowerShell при блокировке npm.ps1 используйте npm.cmd.

## Управление

| Клавиша | Действие |
| --- | --- |
| W | Полностью выпрямиться; отпустить — вернуться в высокую базовую позу |
| L | Группировка, уменьшение момента инерции |
| K | Инерционный аналог twist внутри игровой плоскости |
| Space | Одновременно отпустить обе руки |
| R | Вернуться на стартовую перекладину с нулевыми скоростями |
| Esc | Пауза; RESUME продолжает, MENU возвращает в меню |

Без нажатий Nuro высоко поднимает ноги, слегка сгибая колени и поясницу. Чередуйте эту позу с W (прямое тело) и L (сильная группировка) в ритм качания. Раскачка создаётся только суставными моторами; A/D и дополнительной силы раскачки нет. После release L уменьшает момент инерции; отпустите L, чтобы вытянуть руки для следующего хвата.

## Физика и сцена

TypeScript, Vite, Phaser 3 и встроенный Matter.js. Nuro состоит из 11 rigid bodies и 10 суставов. Два дополнительных физических ограничителя удерживают изгиб между жёсткой грудью и тазом в небольшом диапазоне. Управление использует torque и суставные моторы; шаг физики — 120 Гц.

Одна уличная площадка: стартовый турник чуть выше роста Nuro, второй — правее и выше, снизу широкая плоская зелёная земля. Простые затенённые деревья и холмы создают объём только на заднем фоне. Физика, турники и персонаж остаются в одной 2D-плоскости с боковой камерой. Каждая перекладина имеет твёрдый коллайдер для всех частей тела и область двухручного auto grab. На высокой скорости физический шаг дробится, чтобы конечности не перескакивали через коллайдер. K нагружает суставы корпуса/таза через torque и сохраняет инерцию twist внутри игровой плоскости.

Хват имеет только два состояния: GRABBED / RELEASED. Обе руки должны одновременно подходить к одной перекладине по расстоянию и скорости. Два constraints создаются вместе. Space удаляет оба, сохраняя положения, линейные и угловые скорости. После отпускания есть короткий cooldown. Малое сопротивление воздуха сохраняет полёт по дуге; удар о перекладину физически меняет траекторию. Изменения настроек — в `src/config/constants.ts`: gravity, air drag, linear/angular damping, auto grab и расположение перекладин.

HUD, очков, счётчиков трюков и целей нет. R возвращает на стартовый турник.

## Проверки

```sh
npm run build
npx playwright install chromium
npm test
```

Для установленного Chrome в PowerShell:

```powershell
$env:PLAYWRIGHT_CHANNEL = 'chrome'
npm.cmd test
```

Проверяются меню, отсутствие HUD, боковая поза, W/L/K, двухручный хват, сохранение скоростей при release/regrab, перелёты и многократные рестарты. Физические fixtures для граничных случаев используются только в тестах. В dev-сборке доступен снимок состояния `window.__NURO__.snapshot()`.
